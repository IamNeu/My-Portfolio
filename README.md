## 🧠 About The Project

This portfolio is built to reflect who I actually am as an engineer — not just a frontend dev, but someone who ships full-stack products end-to-end in production.

**Key goals:**
- Showcase real production projects (fintech SaaS, AI workflow tools)
- Present technical depth without sacrificing design quality
- Build everything from scratch using React and Tailwind CSS

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/IamNeu/My-Portfolio.git

# Move into the folder
cd My-Portfolio

# Install dependencies
npm install

# Run the app
npm run dev
```

The app will start at `http://localhost:5173`
